# CloudBreak Files — Marketing site

Static landing page for CloudBreak Files, structured after [umanodesign.studio](https://umanodesign.studio) (floating pill nav, large display type, centered product stage, spacious sections) and colored with the product palette: mist gray, folder blue, hot pink accent, cyan vault.

**Slogan:** CloudBreak Files — A new wave of file browsing.

## Live site

Published via GitHub Pages from this folder:

`https://azevedomedia0.github.io/CloudBreak-Files/`

Workflow: `.github/workflows/deploy-website.yml` (push to `main` under `website/**`, or run manually).

## Preview

```bash
# from repo root
npx --yes serve website -l 4173
# open http://localhost:4173
```

Or open `website/index.html` directly in a browser.
