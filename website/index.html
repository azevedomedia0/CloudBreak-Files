Questions, answered.

Is CloudBreak Files a cloud itself?

No. It sits on top of the clouds and disks you already have — a browser and vault, not another storage silo.

Are my files encrypted by default?

Only when you encrypt them or place them in the vault. We don’t claim encryption for plain previews or demo flags.

Can I use it in the browser?

Yes — the web preview runs the same UI with Web Crypto for vault work. Desktop unlocks the full Tauri bridge, tray, and PTY terminal.

What about Linux?

A native COSMIC port lives in the repo. Architecture and vault crypto are in place; polish continues on Pop!_OS.
